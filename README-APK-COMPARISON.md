# نسخة المشروع مع ناتج APK

هذا المجلد هو مشروع `Masar-final-v29` الأصلي، مع إضافة:

- `apk-web-dist/`: واجهة الويب المضمّنة فعلياً داخل APK.
- `apk-decoded/`: ملفات APK الأساسية المستخرجة للمقارنة.
- `comparison-report.md`: تقرير المقارنة.

لا يتم استبدال `src/` تلقائياً لأن APK لا يحتفظ بملفات TypeScript/React الأصلية؛ الاستبدال الآلي قد يضيّع السورس القابل للتعديل.
